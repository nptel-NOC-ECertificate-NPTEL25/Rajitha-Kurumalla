# Kurumalla Rajitha — Portfolio Website

This is a standalone, responsive static portfolio website package.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For best results, serve this folder with any static web server (for example, `python -m http.server 8000`).

## Contents
- `index.html` — responsive portfolio page with navigation, project gallery, keyboard-accessible image lightbox, training, skills and contact links.
- `assets/` — actual uploaded profile photo, Tekla Structural Designer screenshots, certificate, and resume PDF.

## Publish
Upload the entire extracted folder to a static hosting provider, keeping the `assets` folder beside `index.html`. This package is separate from the Lovable project; it does not automatically publish or change the Lovable preview.

## Notes
- The project screenshots are presented as training/academic models and visualisations, not as claims of structural approval or code compliance.
- Resume PDF is included only if the supplied PDF was present when the package was generated.
